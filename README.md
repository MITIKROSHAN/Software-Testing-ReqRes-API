An educational API testing project using **Postman** and the **ReqRes REST API**. This project demonstrates API testing concepts through different HTTP methods, request validation, response verification, and functional testing.

---

## Project Overview

This repository contains a Postman collection designed to test REST API endpoints using the ReqRes API.

The project covers:

- GET requests for retrieving resources.
- POST requests for creating resources.
- PUT requests for updating resources.
- PATCH requests for partially updating resources.
- DELETE requests for deleting resources.
- API response validation and status code verification.

## Tools and Technologies

- **Postman** – API requests, collections and testing.
- **ReqRes API** – REST API for testing.
- **JSON** – Request and response data format.
- **HTTP Methods** – GET, POST, PUT, PATCH and DELETE.
- **GitHub** – Project hosting and version control.

## HTTP Methods Covered

| Method | Purpose |
|---|---|
| GET | Retrieve data |
| POST | Create new data |
| PUT | Update existing data |
| PATCH | Partially update data |
| DELETE | Delete a resource |

## How to Run the Project

1. Download or clone this repository.
2. Open Postman.
3. Click the Import button.
4. Select the exported Postman collection JSON file.
5. Open the imported collection.
6. Execute individual API requests or run the complete collection.
7. Verify the response body, status code and execution results.
